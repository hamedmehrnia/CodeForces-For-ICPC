## 📂 Repository Structure

Problems are organized based on their **Codeforces problem letter**.

Each letter has its own directory, and the solutions are stored directly inside it.

```text
CodeForces-For-ICPC/
│
├── README.md
├── sample.cpp
│
├── A/
│   ├── 123A.cpp
│   ├── 2032A.cpp
│   └── ...
│
├── B/
│   ├── 456B.cpp
│   └── ...
│
├── C/
│   └── ...
│
└── ...
```

For example, all problems whose Codeforces position is **A** are stored inside the `A/` directory, while their filenames are based on the problem ID.

This keeps the repository simple and makes it easy to browse and find previously solved problems.

## ⚡ `sample.cpp`

`sample.cpp` is my personal **C++ competitive programming template**.

I use it as a starting point whenever I solve a new problem.

Instead of creating a new C++ file and writing the basic structure every time, I simply copy `sample.cpp` into the appropriate directory and rename it using the Codeforces problem ID.

For example:

```bash
cat sample.cpp > A/2032A.cpp
```

Then I can immediately start solving the problem without spending time setting up the basic C++ template.

As I learn and improve, `sample.cpp` may also evolve with new utilities, macros, or commonly used code.
